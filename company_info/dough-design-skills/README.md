# Dough design skills

Five skills for designing in the Dough brand, derived from the Dough brand guidelines and the 47-page company profile.

| Skill | Use for |
|---|---|
| `dough-brand` | Always read first: identity, colour, type, voice, logo rules |
| `dough-profile-layout` | Decks, company profile, case-study pages, editorial layouts |
| `dough-social-campaign` | Social posts, campaign boards, Gen-Z content direction |
| `dough-signage` | Office signage and pictograms |
| `dough-mockups` | Menus, packaging, booths, devices, 3D and standee mockups |

Each folder holds a `SKILL.md`. Drop the folders into a Claude project (or `.claude/skills/`). Reference files: `references/DOUGH GUIDELINES FINAL.pdf` (brand book) and `dough-signage/reference-signage.html`.
